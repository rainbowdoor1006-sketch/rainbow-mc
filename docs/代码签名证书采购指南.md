# 代码签名证书采购指南（Windows exe 去「未知发布者」）

> 日期：2026-10-22
> 适用：RAINBOW MC 启动器（Electron → NSIS → exe）
> 结论先行：**你现在 15 岁，个人买不了正规代码签名证书**（需成年身份证 + 实名核验），
> 现实可行的三条路在文末「给 15 岁的可行方案」。

---

## 一、为什么需要它

现在用户双击 `RAINBOWMC-0.1.0-setup.exe` 会看到：

```
Windows 已保护你的电脑
  不受信任的发布者
  [ 更多信息 ] → [ 仍要运行 ]
```

原因：exe **没有数字签名**。签过名的显示「发布者：RAINBOW DOOR 彩虹门社团」，
SmartScreen 的拦截率也会显著下降（新证书仍会有一定信誉度积累期）。

---

## 二、证书类型（决定价格与体验）

| 类型 | 全称 | 价格区间（年） | SmartScreen | 交付形式 | 审核时长 |
|---|---|---|---|---|---|
| **OV** | Organization Validation | **¥1,500 – 3,500** | 需累积信誉（几周~几月） | 文件证书 / 云签名 | 1–3 工作日 |
| **EV** | Extended Validation | **¥4,000 – 8,000** | **立刻获得信誉** | 必须 USB 硬件令牌 | 3–7 工作日 |
| **个人版** | Individual / IV | ¥800 – 2,000 | 同 OV | 文件 / 云 | 1–3 工作日，**需成年身份证** |

> 价格随代理商与年限浮动，**三年起买通常打 6–7 折**。
> 2023 年 6 月起 CA/B 新规：所有代码签名私钥**必须存放在硬件（USB 令牌）或云 HSM**，不能再给纯 `.pfx` 文件自由保管。
> 这就是为什么现在「文件证书」越来越少，大都改成令牌或云签名。

### 关键差异

- **OV**：能显示公司名，但新证书前几周 SmartScreen 仍可能警告，靠下载量累积信誉
- **EV**：**签完立刻受信**，SmartScreen 基本不拦（代价是贵 + 插 USB 令牌）
- **个人版**：显示个人姓名，不能显示公司

## 三、去哪儿买（国内可开发票）

| 渠道 | 类型 | 备注 |
|---|---|---|
| **DigiCert 官网** | OV / EV | 最贵但最稳，$300–$600/年 |
| **Sectigo（原 Comodo）代理** | OV / EV | 国内代理多，性价比高 |
| **沃通 WoSign / 天威诚信 / 中数** | OV / EV | 国内 CA，能开增值税专票，客服中文 |
| **SSL.com** | OV / EV | 支持支付宝，个人可买（需成年） |
| **KSoftware** | OV | 老牌代理商，价格便宜 |

**建议询价方式**：直接说「Windows 代码签名证书，OV / EV，1 年 / 3 年，要能开发票」，让对方报三家对比。

## 四、购买流程（企业 / 社团主体，OV 为例）

```
① 选型询价 → 下单（需营业执照）
② 提交资料
   · 营业执照扫描件
   · 法人身份证
   · 企业电话（CA 会打这个电话核实，必须能在公开渠道查到）
   · 申请人姓名/职位/邮箱/手机
③ CA 审核（1–3 工作日）
   · 工商信息核验
   · 电话回访（一定要接，问「你们是否申请了代码签名证书」）
④ 收到 USB 令牌（EV）或按邮件指引激活（OV 云签名）
⑤ 安装驱动 + 导入证书 → 用 signtool 签名
⑥ 提交 exe 到 Microsoft 做一次「首次信誉登记」（可选，加速 SmartScreen 通过）
```

### 签名命令（Electron 打包时自动调用）

```bash
# package.json
"win": {
  "signtoolOptions": {
    "certificateSubjectName": "RAINBOW DOOR",
    "timestampServer": "http://timestamp.digicert.com"
  }
}
```

或环境变量方式：

```powershell
$env:CSC_LINK="C:\path\to\cert.pfx"       # 云签名则用证书指纹
$env:CSC_KEY_PASSWORD="******"
npx electron-builder --win nsis
```

## 五、Azure Trusted Signing（微软自家的便宜方案）

| 项 | 内容 |
|---|---|
| 价格 | **约 $9.99/月**（≈ ¥72/月，含每月 5000 次签名） |
| 优点 | 极便宜、无需 USB 令牌、云端签名、CI 友好 |
| 门槛 | **需要企业实体 + 至少 3 年可验证的工商历史**（个人暂不支持，且需在支持国家/地区） |
| 结论 | 社团如果有注册满 3 年的公司主体，这是最划算的 |

## 六、免费方案（开源项目）

| 方案 | 条件 | 说明 |
|---|---|---|
| **SignPath.io 开源免费签名** | 项目开源（OSI 许可） | 免费给开源项目签 OV 证书，需申请审核 |
| 自签名证书 | 无 | **不解决警告**，只是让文件「有签名」，SmartScreen 照样拦，不建议给最终用户 |

> 你的启动器「除授权系统外全部开源」——**理论上符合 SignPath 申请条件**，
> 但要求代码在公开仓库、构建流程可复现。这是**零成本**拿到正规签名的唯一路径。

## 七、给 15 岁的可行方案（按推荐度排序）

### 方案 A：SignPath 开源免费签名（¥0）⭐ 推荐

- 前提：把项目开源到 GitHub（授权系统那部分可以剥离成私有模块）
- 成本：0 元
- 效果：正规 OV 签名，显示发布者名，SmartScreen 逐步放行
- 耗时：申请 3–7 天

### 方案 B：让社团/监护人主体购买 OV（¥1,500–3,500/年）

- 前提：有营业执照（社团若已注册公司/民非）
- 效果：显示「RAINBOW DOOR 彩虹门社团」
- 适合：以后要长期分发、要给人「正规软件」的印象

### 方案 C：先不买，用「说明 + 校验」降低用户疑虑（¥0）

在下载页和启动器文档里写清楚：

```
本软件未购买商业代码签名证书（个人公益项目）。
如果 Windows 提示「未知发布者」，请点「更多信息 → 仍要运行」。
安装包 SHA-256：xxxx（与官网接口返回一致，可自行校验）
```

同时客户端已经做了 **sha256 校验**，被篡改的包会被拒绝 —— 安全上并不比签名差多少，
差的只是「第一眼信任感」。

### 方案 D：EV 证书（¥4,000–8,000/年）

- 只有「必须立刻消除所有警告 + 商业化」才值得
- 15 岁个人无法购买，必须要企业主体

---

## 八、我的建议

```
现在：方案 C（不买）+ 方案 A 申请（并行）
半年后：如果下载量上来了、用户抱怨警告多 → 方案 B
商业化后再考虑：EV 或 Azure Trusted Signing
```

理由：

1. 你现在用户量十几个人，花三千块买证书收益极低
2. 你的项目**开源**，SignPath 免费通道是真实可行的，值得先申请
3. 客户端已经有 sha256 校验，安全性不依赖签名
4. 真正影响体验的是「下载页有没有写清楚」，不是证书

## 九、询价话术模板

> 你好，我需要 **Windows 代码签名证书**（Code Signing Certificate），用途是给 Electron 桌面程序的安装包签名。
> 请报价：
> 1. **OV 版**，1 年 / 3 年，含 USB 令牌或云签名
> 2. **EV 版**，1 年 / 3 年，含 USB 令牌
> 3. 是否能开**增值税普通发票/专用发票**
> 4. 审核需要哪些材料，大概几个工作日
> 5. 是否支持 **Azure Trusted Signing** 或云端签名（我们没有固定办公地点插令牌）

## 十、常见坑

| 坑 | 说明 |
|---|---|
| 买了证书 ≠ 立刻没警告 | OV 新证书仍需累积下载信誉；只有 EV 立刻生效 |
| 私钥不能导出 | 2023 新规后令牌里的私钥不可导出，换电脑要重新申请或迁移令牌 |
| 时间戳服务器必须能连 | 签名时断网会导致「无时间戳」，证书过期后签名失效 |
| 签名后不能再改 exe | 任何改动都要重新签名，所以 CI 里最后一步才是签名 |
| 免费自签名没用 | 用户看到的警告一模一样，别浪费时间 |
