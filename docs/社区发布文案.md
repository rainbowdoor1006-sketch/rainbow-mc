# RAINBOW MC 启动器

一个面向新手的 Minecraft 启动器：**下载 → 双击 → 选版本 → 点启动**，中间的 Java、加载器、资源文件全部自动处理。

## 为什么做这个

我身边很多同学想玩模组，卡在第一步：
- 不知道要装 Java 17
- 不知道 Forge 要跟 MC 版本对应
- 整合包拖进启动器，结果一个模组都没有

所以做了这个启动器，把这些坑全部自动化掉。

## 主要功能

| 功能 | 说明 |
|---|---|
| 一键装加载器 | Forge / NeoForge / Fabric / Quilt，自动匹配版本 |
| 自动补环境 | 缺库文件、缺资源（语言/声音/字体）启动前自动补齐 |
| 整合包导入 | 拖入 `.mrpack`（Modrinth）或 CurseForge 整合包，自动下载全部模组 |
| 资源下载 | 内置 Modrinth 搜索，模组/光影/资源包直接下 |
| 三种登录 | 微软正版 / 社团账号 / **离线登录（无需账号）** |
| 自动更新 | 启动检查更新，静默安装，**存档不会丢** |
| 出问题好排查 | 每次启动生成日志包，自动标出崩在哪一步 |

## 四、各社区注意事项

### MineBBS
- 资源版块需要选择分类（工具/软件），**必须上传或填写外链**，填 SHA256 加分
- 标题不要用夸张词（"最强""第一"），容易被审核压
- 帖子正文里不要放 QQ 群二维码在正文首屏

### 苦力怕论坛
- 需要先在新手区报到（部分版块有发帖权限门槛）
- 工具帖建议附「使用说明 + 常见问题」，纯链接贴会被删

### MC百科社群
- **不要**在主站尝试提交「启动器」条目（主站只收模组/整合包/教程/资料）
- 社群板块可以发，但要写成「经验分享/工具推荐」的形式，不要像纯广告

### B站
- 视频标题：`我做了一个不用配 Java 的 MC 启动器`
- 简介放下载地址（B站会吞外链，可用「评论区置顶」）
- 专栏可以完整搬运上面的正文

### 通用红线
- 不要宣传盗版服务端/破解
- 不要在帖子里要求「必须加群才能下载」
- 提供完整文件校验值，能显著减少被当成病毒的概率
